KoKo Privacy Policy

Effective date: 2026-09-15 · Developer: individual (Apple Developer Program)

KoKo is a native iPhone terminal that connects over SSH to your own Linux server so you can operate Cursor Agent CLI. We take privacy seriously.

1. What data we collect

KoKo does not run its own account system and does not upload your content to our servers. The app only stores on your device:

  • SSH host profiles you add (name, address, port, username, project paths)
  • SSH passwords or private keys (stored in the iOS Keychain)
  • Host key fingerprints (TOFU) and session metadata
  • Terminal scrollback history (local only; can be cleared manually)

2. How data is used

This data is used solely to open SSH connections and render the terminal on your device. SSH traffic goes directly between your iPhone and the server you specify — it does not pass through a KoKo-operated relay.

3. Third-party services

KoKo does not integrate advertising, analytics, or social SDKs. Cursor Agent / Cursor accounts you use on your server are governed by Cursor’s own privacy policy and are unrelated to this app’s developer.

4. Sharing

We do not sell, rent, or share your SSH credentials or terminal content with third parties. We will not disclose local configuration except where required by law.

5. Retention and deletion

All data stays on your device. Delete the app or clear its data in system settings to remove it. You can also clear scrollback in Settings and delete hosts/keys in the app.

6. Children

KoKo is not directed at children under 13. We do not knowingly collect children’s data.

7. Contact

Questions about this policy: use the support channel listed on the App Store listing / GitHub repository for this project.

KoKo 隐私政策

生效日期：2026-09-15 · 开发者：个人开发者（Apple Developer Program）

KoKo 是一款在 iPhone 上通过 SSH 连接你自己的 Linux 服务器、操作 Cursor Agent CLI 的原生终端工具。我们重视你的隐私，说明如下。

1. 我们收集哪些数据

KoKo 不运营自有账号系统，也不向我们的服务器上传你的内容。应用仅在你的设备本地保存：

  • 你添加的 SSH 主机配置（名称、地址、端口、用户名、项目路径）
  • SSH 密码或私钥（使用 iOS Keychain 安全存储）
  • 主机指纹（TOFU）与会话元数据
  • 终端 scrollback 历史（保存在本机，可手动清理）

2. 数据如何使用

上述数据仅用于在本机发起 SSH 连接并显示终端。SSH 流量直接在你的 iPhone 与你指定的服务器之间传输，不经过 KoKo 开发者的中转服务器。

3. 第三方服务

KoKo 不集成广告 SDK、分析 SDK 或社交媒体 SDK。你在服务器上使用的 Cursor Agent / Cursor 账号受 Cursor 自身隐私政策约束，与本应用开发者无关。

4. 数据共享

我们不会出售、出租或向第三方共享你的 SSH 凭据或终端内容。除非法律要求，否则不会披露你的本地配置。

5. 数据保留与删除

所有数据保留在你的设备上。删除 App 或在系统设置中清除 App 数据即可移除。你也可在 App「设置」中清理 scrollback，并在「密钥 / 主机」中删除对应条目。

6. 儿童隐私

KoKo 不面向 13 岁以下儿童，我们不会故意收集儿童数据。

7. 联系

如有隐私问题，请通过 App Store 页面或本项目 GitHub 仓库中的支持渠道联系。
