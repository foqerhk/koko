## 宣传文本（170 字内）
用 iPhone 直连服务器上的 Cursor Agent。真实 SSH 终端，支持 tmux 断线恢复，不是聊天机器人。

## 描述
KoKo 让你在 iPhone 上通过 SSH 操作 Linux 服务器里的 Cursor Agent CLI，保留完整终端体验。

【核心能力】
• 真实 SSH PTY 终端（颜色、光标、菜单、审批 y/n）
• tmux 会话保留，锁屏或断网后可接回
• 可选 agent persist 模式
• App 内生成 Ed25519 / ECDSA / RSA 密钥，私钥存 Keychain
• 主机指纹 TOFU 确认
• 快捷键栏：Esc、Tab、Ctrl+J、方向键、Shift+Tab
• Scrollback 本地全保留，可手动清理
• 检测 Cursor 登录链接，支持复制/打开

【适合谁】
需要在手机上继续与 Cursor Agent 协作的开发者。

【注意】
需自备可 SSH 的 Linux 服务器，并已安装 tmux 与 Cursor CLI（agent）。本 App 不代管 Cursor 账号，不提供云中转。
